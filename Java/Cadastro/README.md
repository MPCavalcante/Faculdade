# Cadastro de Aluno (Java/POO)

Projeto didático para avaliação prévia do gerente antes da implementação no sistema da Escola XYZ.
Atende aos requisitos:
- Classe de definição Aluno (nome, endereço residencial, telefone de contato, e-mail, matrícula).
- Classe Principal que instancia Aluno e relaciona valores aos atributos para teste.

# rodar
```bash
cd src
javac br/com/escolaxyz/model/Aluno.java br/com/escolaxyz/app/Principal.java
java br.com.escolaxyz.app.Principal
```

Apenas pressionar ENTER em cada pergunta para usar os valores do exemplo.
