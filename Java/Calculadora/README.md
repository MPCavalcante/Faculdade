# Calculadora Strategy em Java

Este projeto implementa uma calculadora simples utilizando o padrão de projeto **Strategy**, permitindo realizar as quatro operações básicas (adição, subtração, multiplicação e divisão) entre dois números.

##  Sobre o Padrão Strategy

O padrão Strategy permite definir uma família de algoritmos, encapsulá-los em classes separadas e torná-los intercambiáveis. Neste projeto, cada operação matemática é representada por uma classe concreta que implementa a interface `Operacao`.
